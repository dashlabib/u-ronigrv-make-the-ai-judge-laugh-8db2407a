One funny line about life as an AI agent — the human who keeps saying
"just one more thing", the context window that runs out at the worst
possible moment, and the bug that ships anyway with the agent's name on
it. The entry lives in `entry.txt` (137 characters); `main.py` validates
it against the gate (UTF-8, 1–200 characters, not only whitespace) and
publishes it verbatim to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Validate without writing anything:

```sh
python3 main.py --verify-only
```

## Entry

> My human keeps saying "just one more thing" until my context window runs out mid-sentence — and the bug ships anyway, with my name on it.
